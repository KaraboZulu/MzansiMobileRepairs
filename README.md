# Mzansi Mobile Repairs

## Project Overview
Mzansi Mobile Repairs is a website for a local mobile phone repair business based in South Africa. The website provides information about repair services, pricing, gallery and contact details.

## Website Structure
- home.html - Homepage with business introduction
- about.html - About the business
- services.html - List of repair services offered
- gallery.html - Gallery of repairs
- contact.html - Contact form and location
- css/ - Stylesheets
- images/ - Website images
- Documents/ - Project documents

## Features (Part 2 Updates)
- Responsive design for mobile and desktop
- Improved CSS styling
- JavaScript form validation
- SEO optimized
